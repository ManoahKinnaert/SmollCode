# SmollCode
A minimal coding agent terminal interface.

## Features
- Agentic loop
- Tools: write, read, edit, glob, grep, bash
- Conversation history
- No third party libraries

## Installation
1) From source
```bash
git clone https://github.com/ManoahKinnaert/SmollCode.git 
cd SmollCode && python -m pip install -e .
```
2) Or directly
```bash
python -m pip install git+https://github.com/ManoahKinnaert/SmollCode.git
```

## Usage
```python
python -m SmollCode
```
And of you go...
